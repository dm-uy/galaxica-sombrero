## Verified findings and meaningful limits

1. Original orientation accepted a nonexistent `amended_by` decision. Its reader discards block-list entries and checks supersession without the promised amendment resolution. A copied fixture with DEC-999 absent still produced PASS for the relevant rows. Native resolution must cover scalar, inline and block-list references with every actual target checked; shape cannot authenticate owner consent.
2. Original orientation loses earlier `INPUT` when processing `INPUT +=`, while the migrator enumerates both sets. An owned fixture hid old markup in the first directory. Recursive/exclusion/symlink populations also differ statically. One native file/config resolver must supply orientation, navigation and migration; unsupported/unreadable coverage cannot become PASS.
3. Original multiple alias replacements on one physical Doxyfile line corrupt output through stale offsets. The pure-transformer fixture produced malformed aliases. Native replacement must preserve custom content, compute safe edits and parse/verify the effective resulting aliases before any apply.
4. Static source limits: unreadable-only markup can be reported clean; malformed/fake provenance can pass presence checks; migration sequential writes lack current-byte/symlink preflight and can leave partial effects after a later write error. These additional paths were inspected, not all exploited through real OS failures. Specify refusals, all-file proof before writes and honest partial-effect records rather than copying false success.
5. Source map lifecycle allows `in progress` when newer files are all uncommitted. This is not current complete navigation evidence under the existing neutral map owner. Preserve lifecycle reporting but require current source/config/entity evidence before a map answer; disclosed source fallback remains available.
6. Source profile requires structured-only consent and fixed foreign model/hook bindings, contradicting governing native/project authority. A separate native profile identity must preserve clear matching chat consent and inherited model policy. No universal hook interception or installation claim follows from a manual checker.
7. Source references a missing entry snippet and a three-section handoff AC although the operative form has four headings. Bind the actual seed and preserve all four. Foreign history/private case identities are not current consumer provenance.
8. Candidate ledger/import comparison is C4. C2 can report local candidate status and unavailable downstream comparison; it cannot silently read the old installed ledger or equate absent evidence to no pending candidates.

Six actual original-helper probes are retained: recognizer baseline, dangling amendment, append coverage, alias corruption, migration dry/check and ambiguous-symbol source answer. The recognizer baseline had22 rows/zero failures but used synthetic placeholders; it is not a materialized consumer PASS. Dry/check leaves copied fixture bytes unchanged. No native port, original-source apply, original full suite or Doxygen build was run here.
