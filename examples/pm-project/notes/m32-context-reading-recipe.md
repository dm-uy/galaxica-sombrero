# M32 — optional long-source reading recipe

Use when a source is too long to deliver reliably in one tool response. Preserve the task's existing authority and exact source scope. Required normative bodies still need complete reading; section selection applies to the research corpus and optional details.

1. Bind the actual source path and content identity. Read its actual TOC/index first, if any. Select sections answering the question and name excluded areas.
2. Resolve each selected boundary against current source bytes. With tags require unique start/end, correct order and LIFO nesting; reconcile the TOC heading/anchor with its actual body. With headings/ranges record the heading level, actual range and resolution method; absence of custom tags is not corruption.
3. Read manageable chunks. Track selected ranges, actually delivered ranges and remaining gaps separately. A locator/hash/command is not delivery. If tool output is truncated, mark its read extent unknown unless the complete prefix is identifiable, then reread the missing or uncertain range in smaller chunks. Do not certify completeness from a visible closing tag alone.
4. Before synthesis compare source identity with the one used to resolve/read. If changed, find actual changed ranges and renew affected boundaries/reads; unchanged independent evidence may be reused explicitly. If freshness or coverage cannot be established, withhold the dependent claim and name the missing evidence.
5. Return question → section/range → evidence, coverage/gaps, source identity and limits. This proves only the claimed delivery/check scope, not mental adoption, scientific truth or live reality described by the document.

Do not introduce permanent registries, mandatory tags, global token quotas or a new helper by default. Apply existing task records and real tool availability.

## Disposition and evidence

Retained as an optional project recipe after bounded checks; see [M32 findings and limits](m32-book-findings.md#t2-and-t3--bounded-reading-checks). This record creates no mandatory skill, registry, parser or phase. It does not replace full reading required by the governing owners.
