# Native consumer PM profile 1.0.0

Identity: `methodology-consumer-pm/1.0.0`; opt-in only, source package2.3.0 over neutral1.1.0. Wire methodology-codex/2.0.0/schema2 remains unchanged. This carrier composes existing full owners; it creates neither consumer consent nor a replacement constitution.

## Adoption and homes

Read actual project instructions first. Owner/project rules refine this profile and win. Authenticate exact existing action, artifact and file scope; preserve settled clear consent and keep specification/run permission separate from current-result integration. A template, worker assertion or structural metadata cannot authenticate human authority. Record actual actor and clock; reusable slots are not filled records.

Declare CONVENTIONS front matter profile/version, mode `single-layer` or `layered`, layer relative path, and `homes` for entry, vision, roadmap, handoff, tasks, decisions, specs, recon, notes, open_questions and config. Root defaults AGENTS/VISION/ROADMAP/HANDOFF/TASKS, docs/decisions, specs, docs/recon, notes, OPEN_QUESTIONS, Doxyfile. Existing declared names win; absent preferred VISION never implies a new product. Layered flow reads root vision/architecture/decisions, writes only declared layer route/tasks/handoff/specs/recon/notes; external architect reads that layer and owns root normative records. No concurrent writer to one path. Map original homes, history and inbound links before proposing migration; never overwrite or relocate without exact granted migration. Accepted decision bodies are immutable; only status/superseded_by/amended_by metadata changes under authentic decision. Supersession is reciprocal; every scalar/inline/block-list amendment resolves each exact DEC id. Parent allocates reservations in order from highest existing/reserved id, no branch-local selection.

Always read actual entry, vision, route, handoff and tasks, then relevant links. Limits are inclusive: total600 lines; handoff150 lines; date-led State items2 (exclude fences and tables); route step300 characters and whole route25000 characters. Overrides are nonnegative integers under `overrides`, with `overrides_decision` referencing authentic authority. Retain overflow under linked notes, never silently delete history. Long technical forms retain full current document/graph/spec protocols; records remain English unless controlling project instruction refines language.

Active packet and handoff update together. Archive unfinished rows only after actual result decision. Cleanup, commit, merge and publication need matching separate authority.

Handoff headings exactly once and in order: Blocked on the owner, State, Queue, Traps. Owner block first, including pending result/commit decisions. State carries current and previous checkpoint plus actual revision/check identity/uncommitted reason. Queue points to current TASKS and exact next task; it does not duplicate packet. Traps preserve cause until mechanized/superseded or linked retention after three irrelevant checkpoints. Final owner report uses Blocked on the owner / Changed / Found for this opted-in profile, each unconfirmed claim names its lookup.
