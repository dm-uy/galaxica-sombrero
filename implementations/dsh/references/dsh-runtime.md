## Native surface this harness actually supplies

| Commands | `bash`, `read`, `write`, `edit`, `glob`, `grep`, `todo_write`, `present`, web tools, jobs, skills | Availability is the session preset's decision. A missing tool is not authority to substitute another. |

## Native orchestration forms

The authorized root may use either native form and must record which it used.

1. **Role-named delegation tools.** A session preset that includes this package's optional role-delegation patch registers one `subagent` instance per role, each with its own `persona`, `toolFilter` and `maxDepth`. The parent still writes the exact role brief, including the instruction to read that role's carrier, and still authenticates the return. This is the only shipped form in which a child's tool surface differs by role.
2. **The `workflow` tool.** A single authorized root may express fan-out and phased work in a script. Script agents cannot select a preset, effort or isolation level, and a workflow's children are not in the parent's subagent catalog; their results arrive as the script's return value.

Neither form proves independence. Record the actual actor, session and tool identities, and the contamination limits, next to the evidence.
